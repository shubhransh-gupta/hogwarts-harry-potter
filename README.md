## 📜 The Tale of Two Worlds

```
========================================================================================
  🎟️  H O G W A R T S   E X P R E S S   ·   O N E - W A Y   T I C K E T
----------------------------------------------------------------------------------------
  PASSENGER : First Year Student          LOCOMOTIVE  : 5972 Hogwarts Castle
  FROM      : Lucknow Charbagh (Plat 9¾)   DESTINATION : Dehradun Valley (Himalayas)
  DEPARTURE : 11:00 AM Sharp              CLASS       : Witchcraft & Wizardry
========================================================================================
```

Between Platforms 9 and 10 of the majestic Indo-Saracenic red-brick arches of **Lucknow Charbagh Railway Station**, ordinary commuters see only a solid masonry wall. But walk straight forward with your luggage trolley, and the barrier parts into **Platform 9¾**.

There stands the legendary **5972 Hogwarts Express**—a 4-6-0 locomotive gleaming in crimson and glossy black, steam pouring from its brass-capped smokestack. Boarding the vintage passenger carriages takes you on an unforgettable journey climbing into the winding cedar and pine mountain ridges of **Dehradun**, where the ancient Gothic towers of Hogwarts rise above the clouds and mirror across the Doon Great Lake.

### 1. 🚂 Platform 9¾ (Lucknow Charbagh)
The grand station with Victorian ironwork trusses, sandstone chattris, waiting benches, the departure clock, and the magical **Platform 9¾ brick barrier** where a brass luggage trolley laden with wizard trunks and Hedwig’s owl cage is half-submerged into the masonry. Alongside sits the waiting **5972 Steam Engine**.

### 2. 🌉 The Himalayan Mountain Viaduct
A monumental multi-arch stone aqueduct bridging a dizzying mountain gorge. Watch an animated Hogwarts Express traverse the high tracks with billowing steam as mountain mists drift lazily beneath.

### 3. 🏰 The Castle Courtyard & Clock Tower
The cobblestone heart of Hogwarts framed by Gothic cloisters and an ancient stone fountain. At its head rises the massive Clock Tower with a swinging brass pendulum and moving clock hands.

### 4. 🕯️ The Great Hall
Massive cathedral arches, pointed stained-glass windows glowing amber, long banquet tables, a roaring stone hearth, and **dozens of enchanted floating candles** bobbing gracefully overhead.

### 5. 🔭 Astronomy Tower Spire
The highest battlement terrace of Hogwarts. Features rotating brass armillary astrological rings, astronomical instruments, and a 360° panoramic vista of the surrounding Garhwal & Shivalik Himalayan peaks.

### 6. 🧹 The Quidditch Pitch
An emerald oval stadium nestled in a mountain bowl, framed by towering spectator towers dressed in the heraldry of **Gryffindor**, **Slytherin**, **Ravenclaw**, and **Hufflepuff**. At each end soar three golden goal hoops. Keep your eyes sharp: the **Golden Snitch** flutters dynamically across the pitch—chase it down or summon it with magic to win +150 House points!

### 7. 🎃 Hagrid’s Hut & Giant Pumpkin Patch
An octagonal rustic stone cottage with a smoking stone chimney, heavy timber door, and Hagrid’s fenced pumpkin patch containing **gigantic magical pumpkins** that can be targeted and levitated into the sky.

### 8. 🌲 The Forbidden Himalayan Deodar Forest
A dense, whispering grove of ancient Himalayan deodars and blue-glowing mystical mushrooms. In its clearing stands an ancient druidic stone circle carved with glowing celestial runes, watched over by floating spirit will-o'-the-wisps.

## 🎵 Real-Time Web Audio API Synthesizer

**0 MB audio downloads.** Every sound in the game is procedurally generated in the browser using the **Web Audio API**:
* **Track 1**: *Hedwig’s Himalayan Theme* — Authentic celesta bells with gentle string accompaniment.
* **Track 2**: *Platform 9¾ Lucknow Departure* — Rhythmic 3/4 train waltz.
* **Track 3**: *Doon Valley Castle Nocturne* — Ambient mystical night chords.
* **SFX**: Dynamic wand ignitions, celestial Patronus chimes, levitation hums, flame whooshes, tumbler clicks, and the twin-tone 4-6-0 steam whistle (`587 Hz` + `740 Hz`).

## ⚡ Technical Highlights

* **Ultra Lightweight**: Pure procedural geometry constructed with Three.js primitives. The entire production bundle is **~150 kB gzipped**!
* **Cel-Shaded Aesthetic**: Toon shading, custom gradient materials, soft shadow cascades, and distance atmospheric mountain fog.
* **Zero External Network Dependencies**: Self-contained procedural models and Web Audio synthesis run smoothly on low-end laptops and mobile phones at 60 FPS.

## 🛠️ Local Development

```bash
# Clone the repository
git clone https://github.com/shubhransh-gupta/hogwarts-harry-potter.git

# Enter project directory
cd hogwarts-harry-potter

# Install dependencies
npm install

# Start development server
npm run dev
```

Open `http://localhost:5173` in your browser.

To create an optimized production build:
```bash
npm run build
```
